# demo_flanks

Small public flank-based demo fixture for one-shot `pydaglogo` examples.

- input table: `demo_flanks.csv`
- fast ztest demo background: `reference_bundle_ztest/background_samples.csv`
- fast Fisher demo background: `reference_bundle_fisher/background_samples.csv`

These files are example assets for package demos. They are not part of the
official exact R/Python validation benchmark.
